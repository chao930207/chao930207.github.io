# 前言

有了自己的域名之后，不满足于 Chaos' blog，总想各种折腾，但是需要服务器。
各家云厂商优惠活动一开始很便宜实惠，但等续费时就不是优惠活动价了。
网上翻找资料，刚好有张 Visa 信用卡，于是在 always free 里 google cloud 和 oracle cloud 中选择了 oracle cloud （看中了它的免费账户）

# 大致流程

  • 注册账户
    • 注册过程中不必担心资金问题，只用于验证，会退回
  • 创建免费实例
    • 一种是 2 台基于 AMD 的的虚拟机，规格 1/8 OCPU 和 1GB 内存
    • 一种是基于 Arm 的 Ampere A1 虚拟机，OCPU 和内存比例为 1:6，可以建 4 OCPU 24 GB * 1 或者 2 OCPU 12 GB * 2 或者 1 OCPU 6 GB *4
    • 另外需要注意的是，磁盘总共 200GB，2 种共享，如果你需要多个虚拟机的话，需要合理分配，由于本身限制，最多持有 4 台虚拟机

我嘛 1 台就够折腾了，于是创建了基于 Arm 的 Ampere A1 虚拟机，规格 4 OCPU 24GB 磁盘 50GB（默认，不够再加）。

具体的步骤我就不一一列了，参考网上文档就可以。

创建实例时，确定选有提示 符合始终免费条件 的

# 2026-07-03 更新

昨天登录 Oracle Cloud，发现免费额度降了，从 2026-06-22 开始，Ampere A1 虚拟机的总规格降至 2 OCPU 12GB，不得已进行了降级调整
调整完后部分进程因未加入开机启动，不得已重新调整
